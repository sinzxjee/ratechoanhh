## Expanded meme pools

`meme-cat-sheet.png` contains 20 generated cat reaction portraits in a 5×4 grid. `meme-dog-sheet.png` contains 5 generated dog reaction portraits in a 5×1 grid. Both were made with the built-in image generation tool for this website; each tile is displayed separately by CSS. The five earlier cat memes and five earlier dog memes bring the totals to 25 cats and 10 dogs. Goat and otter each retain their existing set of five photos.
